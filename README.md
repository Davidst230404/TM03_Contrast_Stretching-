## Deskripsi

Praktikum TM 03 Teknik Pengolahan Citra mengenai contrast stretching
menggunakan Look Up Table (LUT) pada citra `Pout.tif`.

## Proses

1. Membaca citra `Pout.tif`
2. Menentukan nilai minimum dan maksimum citra
3. Menentukan nilai output minimum dan maksimum
4. Membuat LUT berdasarkan rumus contrast stretching
5. Mengonversikan citra menggunakan LUT
6. Menampilkan citra input dan hasil
7. Menampilkan histogram citra input dan hasil

## Parameter

- a = 74
- b = 224
- c = 5
- d = 255

## Rumus

y = ((x - a) / (b - a)) × (d - c) + c
